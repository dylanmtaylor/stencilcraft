## Known limitations

- Profile links are derived from `Operation.kind` + `settings` because the
  document model has no profile field; `Unlink` is a session-only detach marker
  (`StencilApp.detached_ops`) and is not saved. A persisted link needs a document
  field (craft-libs `Operation.preset_id`).
- Import/export use the desktop file dialog and are not covered by the harness
  specs.
