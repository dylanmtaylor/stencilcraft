# Design panel

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02. Text, Shapes, Images and Upload have their own pages:
[text](text.md), [shapes](shapes.md), [images and upload](images-and-upload.md).

### Templates
- **What**: guide backgrounds for sizing a design (garments, home items, card sizes). Pick
  a category, then the size that fits.
- **Options**: newer releases add filters to narrow templates by cutting machine.
- **Behaviour**: a template is placed with the Guide operation. It is never sent to the
  machine. It can be renamed, moved, hidden, duplicated or deleted in the Layers panel.
- **Availability**: Guide layers are desktop only (Windows/Mac).
- **Sources**: [Using Templates](https://help.cricut.com/hc/en-us/articles/360009548273-Using-Templates-in-Design-Space), [Design Space FAQ](https://help.cricut.com/hc/en-us/articles/360009503353-Design-Space-FAQ).

### Projects (from the Canvas)
- **What**: open a Ready-to-Make project from inside the Canvas.
- **Availability**: Cricut Access or purchase for most.
- **Sources**: [Ready-to-Make projects](https://help.cricut.com/hc/en-us/articles/360009509593-Using-Ready-to-Make-Projects-in-Design-Space).

### Monogram Maker
- **What**: builds a monogram from up to four initials.
- **Options**: Classic or Thematic type, a text style and a frame. Filter to cut-only
  styles or cut-and-draw styles.
- **Availability**: beta, English only, Cricut Access, Design Space for Desktop only.
- **Sources**: [Monogram Maker](https://help.cricut.com/hc/en-us/articles/6143263107991-Design-Space-Using-Monogram-Maker).

### Editable images
- **What**: library images with text you can change. The editable parts are highlighted
  in blue, and the image arrives on the Canvas as an attached group.
- **Where**: the Editable Images icon on the Canvas, or the Editable Text filter in Images.
- **Sources**: [Using Images](https://help.cricut.com/hc/en-us/articles/360009426074-Using-Images-in-Design-Space).

### Phrases

- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### AI Create and AI Edit
- **What**: generate an image from a chosen style, an optional reference photo and an
  optional prompt. AI Edit restyles an image already on the Canvas. The Saved tab lists
  earlier generations. Since v10.5, AI Text edit refines a result with a text description.
- **Availability**: every generation uses Cricut Credits. Free accounts get a few each
  month, Cricut Access gets more, and new StickerPix machines add some. Marked with an AI
  icon.
- **Sources**: [Cricut and AI](https://help.cricut.com/hc/en-us/articles/43714290860311-Cricut-and-AI-How-To-Use-It-What-Happens-and-Related-Questions), [release notes](https://help.cricut.com/hc/en-us/articles/27054006457111-Design-Space-Release-Notes), [blog: Create AI](https://cricut.com/blog/introducing-create-ai/).

### AI Generated image filter
- **What**: a filter in Images that shows only images made with Create AI.
- **Sources**: [release notes](https://help.cricut.com/hc/en-us/articles/27054006457111-Design-Space-Release-Notes).
