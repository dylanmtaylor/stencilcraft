# Edit bar

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02. The Edit bar sits above the Canvas. It shows more
controls when text is selected; those are on [text](text.md). Operations are on
[operations and linetypes](operations-and-linetypes.md).

### Undo / Redo
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Operation
- **What**: how the machine treats the layer: cut, draw, score and so on. Each operation is
  described in [operations and linetypes](operations-and-linetypes.md).
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide), [Selecting Operation](https://help.cricut.com/hc/en-us/articles/26922998476183-Design-Space-Selecting-Operation).

### Select all / deselect
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Edit menu: cut, copy, paste
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Fill
- **What**: for a Print Then Cut layer: print the original artwork, a solid colour, or a
  pattern.
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide), [Patterns](https://help.cricut.com/hc/en-us/articles/360009423714-Using-Patterns-in-Design-Space).

### Edit Pattern
- **What**: change a pattern fill's scale, position and rotation. The library has hundreds
  of patterns, and users can upload their own.
- **Where**: a button at the bottom of the pattern panel.
- **Availability**: many library patterns are Cricut Access content.
- **Sources**: [Patterns](https://help.cricut.com/hc/en-us/articles/360009423714-Using-Patterns-in-Design-Space).

### Linetype colour
- **What**: colour swatch of a cut or draw layer. Layers of different colours go on
  different mats.
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Align
- **What**: align two or more objects left, centre, right, top, middle or bottom, and
  distribute them evenly.
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Arrange
- **What**: stacking order: Move to Back, Move Backward, Move Forward, Move to Front. The
  Layers panel shows the new order.
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Flip / Mirror
- **What**: flip the selection horizontally or vertically. This is different from
  mirroring a mat on the Make screen.
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Size
- **What**: type an exact width or height, or step it in 0.1 increments. Proportions stay
  linked unless the lock is opened.
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Rotate
- **What**: type an exact angle, or step it 1° at a time.
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Position
- **What**: type X and Y, or drag on the Canvas.
- **Sources**: [StickerPix features](https://help.cricut.com/hc/en-us/articles/43562317923095-Understanding-Design-Space-features-for-Cricut-StickerPix-Print-Cut).

### Offset
- **What**: adds a new layer that follows the selection's outline, outside or inside it at
  a set distance.
- **Options**: distance, rounded or sharp corners, and Weld Offsets. Weld Offsets is on by
  default for text, multi-layer designs or several objects, and merges all offsets into one
  layer. Turn it off to get one offset per piece.
- **Notes**: works best on closed paths; open Draw paths may give poor results. For stickers,
  flatten the artwork onto the offset before printing.
- **Where**: Effects / toolbar.
- **Sources**: [Offset](https://help.cricut.com/hc/en-us/articles/360061650414-How-to-use-the-Offset-feature-in-Design-Space).

### Warp
- **What**: bends a layer (text, images, shapes, multi-layer) into one of 30 preset warp
  styles, with a strength slider.
- **Rules**: warped objects cannot be welded, sliced or ungrouped to letters, and other
  layers cannot be dragged into them. Printable Print Then Cut images cannot be warped.
- **Availability**: Cricut Access. Anyone can preview it. Desktop v7.31 and later.
- **Sources**: [Warp](https://help.cricut.com/hc/en-us/articles/11736800185623-How-to-use-Warp-in-Design-Space).

### Create Sticker
- **What**: turns the selection into a printable sticker in one step. It flattens the
  design, can add a border (an offset), and lets you pick die cut (through the backing) or
  kiss cut (top layer only).
- **Availability**: Cricut Access; desktop v8.15 and later (introduced December 2023).
- **Sources**: [Create Sticker](https://help.cricut.com/hc/en-us/articles/19366738622359-How-to-use-Create-Sticker-in-Design-Space), [blog: Create Sticker](https://cricut.com/blog/gb/introducing-create-sticker-in-design-space/).
