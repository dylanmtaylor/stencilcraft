# Home screen and projects

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02.

### Home screen
- **What**: the start screen. You can browse popular project categories and search for
  projects, images, fonts and user profiles.
- **Where**: top bar holds the menu (profile, machine selection, machine setup, settings),
  notifications and help. Bottom bar: Home, Cricut Access, New Project, My Stuff, More (Heat
  Guide, Shop).
- **Availability**: all platforms. The Home tab is disabled offline.
- **Sources**: [Home screen guide](https://help.cricut.com/hc/en-us/articles/26751670743831-Home-screen-Design-Space-Guide).

### New Project
- **What**: opens an empty Canvas. Since v10.10 a project's base type can be changed from
  the Canvas preview.
- **Where**: Home bottom bar.
- **Availability**: all platforms.
- **Sources**: [Home screen guide](https://help.cricut.com/hc/en-us/articles/26751670743831-Home-screen-Design-Space-Guide), [release notes](https://help.cricut.com/hc/en-us/articles/27054006457111-Design-Space-Release-Notes).

### Ready-to-Make projects
- **What**: finished vendor projects you open, customise and cut. Search on Home, then
  filter by category.
- **Availability**: many need a Cricut Access subscription or a purchase; some are free.
- **Sources**: [Ready-to-Make projects](https://help.cricut.com/hc/en-us/articles/360009509593-Using-Ready-to-Make-Projects-in-Design-Space), [free and purchased content](https://help.cricut.com/hc/en-us/articles/360009552733-How-to-find-free-and-purchased-content-in-Design-Space).

### My Stuff
- **What**: your saved and bookmarked projects and images, and your uploads.
- **Where**: Home bottom bar.
- **Availability**: all platforms. It needs the cloud account; offline, only downloaded
  items show.
- **Sources**: [My Stuff and Collections](https://help.cricut.com/hc/en-us/articles/1500003203902-Using-My-Stuff-and-Collections-in-Design-Space).

### Collections
- **What**: folders that group projects, uploaded images and bookmarks. One collection
  holds up to 1,000 projects.
- **Where**: My Stuff.
- **Availability**: online only (unavailable offline).
- **Sources**: [My Stuff and Collections](https://help.cricut.com/hc/en-us/articles/1500003203902-Using-My-Stuff-and-Collections-in-Design-Space), [offline feature](https://help.cricut.com/hc/en-us/articles/360033894014-Design-Space-Offline-Feature).

### Save, Save As, Auto Save
- **What**: Save stores the project in the account cloud, so it opens on Windows, Mac,
  iOS and Android. Save As makes a renamed copy. On first save on desktop you choose the
  default: cloud only, or cloud and computer. Auto Save (v9.72, June 2026) is on by
  default for new desktop projects and can be turned off from the Save menu.
- **Availability**: cloud save needs an account and a connection. Device-only saves do
  not sync on their own.
- **Sources**: [offline feature](https://help.cricut.com/hc/en-us/articles/360033894014-Design-Space-Offline-Feature), [release notes](https://help.cricut.com/hc/en-us/articles/27054006457111-Design-Space-Release-Notes).

### Project sharing
- **What**: publish a project to other Design Space users, or copy a direct link.
  Options: photos of the finished piece, a name, a description and up to 15 tags. Shared
  project details can be edited later from My Stuff.
- **Availability**: account and cloud. Older articles say Android lacked sharing.
- **Sources**: [share a project](https://help.cricut.com/hc/en-us/articles/360009377574-How-do-I-share-my-Design-Space-project), [edit a shared project](https://help.cricut.com/hc/en-us/articles/360009500053-How-do-I-edit-a-shared-project-in-Design-Space).

### Heat Guide link
- **What**: a link to Cricut's heat-press settings guide for iron-on and similar materials.
- **Where**: Home › More.
- **Sources**: [Home screen guide](https://help.cricut.com/hc/en-us/articles/26751670743831-Home-screen-Design-Space-Guide).

### AI Project Designer
- **What**: a conversational assistant (2026) that builds a personalised, ready-to-make
  design from a chat.
- **Availability**: uses Cricut Credits. Free accounts get a one-time deposit; Cricut
  Access gets credits each month.
- **Sources**: [blog: AI Project Designer](https://cricut.com/blog/cricut-launches-ai-project-designer/), [Cricut and AI](https://help.cricut.com/hc/en-us/articles/43714290860311-Cricut-and-AI-How-To-Use-It-What-Happens-and-Related-Questions).

### Help chatbot
- **What**: an in-app help chat. Since v10.10 it docks on the right of non-Canvas screens
  and floats as a draggable window on the Canvas.
- **Sources**: [release notes](https://help.cricut.com/hc/en-us/articles/27054006457111-Design-Space-Release-Notes).
