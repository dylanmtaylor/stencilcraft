### Machine setup and firmware
- **What**: new machines are registered and set up from the Design Space menu (machine
  setup). Firmware updates also come through Design Space.
- **Availability**: needs an account and a connection; new machine setup is not possible
  offline on iOS.
- **Sources**: [Home screen guide](https://help.cricut.com/hc/en-us/articles/26751670743831-Home-screen-Design-Space-Guide), [Design Space FAQ](https://help.cricut.com/hc/en-us/articles/360009503353-Design-Space-FAQ).

### Older machines and discontinued software
- **What**: older machines and cartridge-based software (such as Cricut Craft Room) are
  listed as discontinued; cartridge handbooks are still published.
- **Sources**: [discontinued software](https://help.cricut.com/hc/en-us/articles/360009381074-Discontinued-Software-and-Programs), [cartridge handbooks](https://help.cricut.com/hc/en-us/articles/360009424614-Cartridge-Handbooks).
