# Prepare and Make screens

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02. Make It on the Canvas opens the Prepare screen (mat
preview), then the Make screen (the cut).

### Prepare screen: mat preview
- **What**: one mat per material/colour, with the pieces laid out on it. This is the last
  chance to arrange things before cutting.
- **Sources**: [Prepare screen guide](https://help.cricut.com/hc/en-us/articles/26762475430167-Prepare-screen-Design-Space-Guide).

### Move, rotate and hide pieces on a mat
- **What**: drag pieces on a mat, or hide them. Moved pieces keep their position.
- **Sources**: [Prepare screen guide](https://help.cricut.com/hc/en-us/articles/26762475430167-Prepare-screen-Design-Space-Guide).

### Move object to another mat
- **What**: send the selected pieces to a new mat or an existing one.
- **Sources**: [Prepare screen guide](https://help.cricut.com/hc/en-us/articles/26762475430167-Prepare-screen-Design-Space-Guide).

### Project copies
- **What**: cut several copies. Each object is repeated that many times and spills onto
  new mats as needed. Set this before moving or hiding pieces, because changing it resets
  the mats.
- **Sources**: [Prepare screen guide](https://help.cricut.com/hc/en-us/articles/26762475430167-Prepare-screen-Design-Space-Guide).

### Mirror per mat
- **What**: mirrors the contents of one mat, for iron-on materials cut face down. One mat
  at a time. Design Space turns it on automatically for iron-on and Infusible Ink
  materials if it is off.
- **Sources**: [mirror your design](https://help.cricut.com/hc/en-us/articles/360009432354-How-to-mirror-your-design-in-Design-Space).

### Material size
- **What**: pick the mat or sheet size. Only sizes the machine supports and that fit the
  largest piece are listed.
- **Sources**: [change mat or material size](https://help.cricut.com/hc/en-us/articles/360009504333-How-to-change-the-mat-or-material-size-in-Design-Space).

### Material load type
- **What**: On Mat, or Without Mat for Smart Materials. A default per machine is set in
  Settings.
- **Sources**: [material load type](https://help.cricut.com/hc/en-us/articles/360043263413-How-to-Select-Material-Load-Type-in-Design-Space), [Design Space Settings](https://help.cricut.com/hc/en-us/articles/360023589934-Design-Space-Settings).

### Connect machine
- **What**: connect over USB or Bluetooth before cutting.
- **Sources**: [Make screen guide](https://help.cricut.com/hc/en-us/articles/26751753338007-Make-screen-Design-Space-Guide).

### Base material selection
- **What**: pick a popular setting, a bookmarked one, or browse the full list. Each comes
  with preset pressure and number of passes (multi-cut).
- **Sources**: [Make screen guide](https://help.cricut.com/hc/en-us/articles/26751753338007-Make-screen-Design-Space-Guide), [material settings](https://help.cricut.com/hc/en-us/articles/360009501793-How-do-I-choose-material-settings).

### Pressure: Default / More / Less
- **What**: a quick adjustment for this cut only. It is not saved; to keep a change, make
  a custom material.
- **Sources**: [cut pressure](https://help.cricut.com/hc/en-us/articles/360009383274-How-do-I-change-the-cut-pressure-on-my-machine).

### Remember material settings
- **What**: keeps the material choice between mats of the current project only.
- **Sources**: [cut pressure](https://help.cricut.com/hc/en-us/articles/360009383274-How-do-I-change-the-cut-pressure-on-my-machine).

### Load tools and materials list
- **What**: tells you which tool goes in which clamp and which material to load, for each
  mat, based on its operations and material.
- **Sources**: [Make screen guide](https://help.cricut.com/hc/en-us/articles/26751753338007-Make-screen-Design-Space-Guide).

### Edit from the Make screen
- **What**: go back to rearrange pieces or change Mirror without leaving the flow. Cancel
  returns to Prepare.
- **Sources**: [Make screen guide](https://help.cricut.com/hc/en-us/articles/26751753338007-Make-screen-Design-Space-Guide).

### Machine buttons (Load, Go, Pause)
- **What**: the machine's load and go buttons light up when Design Space is ready. A 2026
  fix touched Load-button behaviour on Maker 5 and Explore 5.
- **Sources**: [iOS Load/Go article](https://help.cricut.com/hc/en-us/articles/35502193387159-Machine-buttons-to-load-and-go-don-t-light-up-when-cutting-from-Design-Space-for-iOS), [release notes](https://help.cricut.com/hc/en-us/articles/27054006457111-Design-Space-Release-Notes).

### Send to printer (Print Then Cut)
- **What**: Print Then Cut mats print first. See [print then cut](print-then-cut.md).
- **Sources**: [Print Then Cut](https://help.cricut.com/hc/en-us/articles/360009387274-How-to-Print-Then-Cut-in-Design-Space).
