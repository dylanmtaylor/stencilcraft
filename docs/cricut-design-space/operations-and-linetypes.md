# Operations and linetypes

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02. The operation is chosen per layer on the
[Edit bar](edit-bar.md). It decides which tool is used and which mat the layer goes on.

| Operation | What the machine does | Tool | Machines | Notes |
| --- | --- | --- | --- | --- |
| Basic Cut | cuts the outline | Fine-Point, Deep-Point or Performance blade | all | the default |
| Pen / Draw | draws the outline (or a writing font) | Cricut pens and markers | all | pen colour shown on Canvas |
| Score | creases a fold line | Scoring Stylus (Explore 4 and earlier, Maker 4 and earlier, Venture) or Scoring Wheel (Maker) | Explore, Maker, Venture; Joy 2 and Explore 5 ship a Scoring Tool | Score lines are attached to the cut layer |
| Engrave | engraves the line | Engraving Tip / Engraving Tool | Maker family | blanks up to 1/8 in (3 mm); a blue guide layer positions the blank |
| Deboss | presses a line into the material | Debossing Tip | Maker family | |
| Wave (Wavy) | cuts a wavy line | Wavy Blade | Maker family | |
| Perforate | cuts a dashed tear line | Perforation Blade | Maker family | |
| Foil | presses foil from a transfer sheet | Foil Transfer Tool (fine, medium, bold tips); Joy version separate | Explore, Maker; Joy (own tool) | desktop only; the Joy foil tool is not supported on mobile |
| Print Then Cut | prints on a home printer, then cuts around it using sensor marks | blade plus sensor | machines with a sensor | see [print then cut](print-then-cut.md) |
| Guide | shown on Canvas only, never sent | — | — | used by Templates; desktop only |

### Attach for non-cut operations
- **What**: Draw, Score and Foil layers must be attached to a cut layer to land in the
  right place on the same mat.
- **Sources**: [Attach](https://help.cricut.com/hc/en-us/articles/360009380514-How-to-use-Attach-in-Design-Space).

### Tool numbers
- **What**: the tool list numbers each tool (for example, the Wavy Blade is 31) so the
  machine and Design Space can match the tool to the operation.
- **Sources**: [Selecting Operation](https://help.cricut.com/hc/en-us/articles/26922998476183-Design-Space-Selecting-Operation).
