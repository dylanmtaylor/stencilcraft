# Print Then Cut

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02.

### Print Then Cut workflow
- **What**: a printable layer goes to a home printer with sensor marks around it. The
  machine then scans the marks and cuts around the print.
- **Steps**: set the layer's operation to Print Then Cut (single-layer images) or Flatten
  several layers; Make It; Send to Printer; load the print; the machine scans and cuts.
- **Sources**: [Print Then Cut](https://help.cricut.com/hc/en-us/articles/360009387274-How-to-Print-Then-Cut-in-Design-Space).

### Bleed
- **What**: every printable image gets a bleed by default: the print runs a little past
  the cut line. It can be turned off.
- **Where**: desktop: the Send to Printer dialog. Mobile: Make It › mat options › Bleed.
- **Sources**: [Print Then Cut](https://help.cricut.com/hc/en-us/articles/360009387274-How-to-Print-Then-Cut-in-Design-Space).

### System print dialog
- **What**: an option to print through the operating system's dialog. Printer scaling and
  fit-to-page must be off.
- **Sources**: [Print Then Cut](https://help.cricut.com/hc/en-us/articles/360009387274-How-to-Print-Then-Cut-in-Design-Space), [sensor marks](https://help.cricut.com/hc/en-us/articles/360009426434-Machine-cannot-read-the-cut-sensor-marks).

### Sensor marks
- **What**: printed marks the machine's optical sensor reads to find the print. They must
  not be cropped, resized or covered. Printing from a saved PDF outside Design Space gives
  marks of the wrong size, so print within the same session. Keep the sensor window clean.
- **Sources**: [sensor marks](https://help.cricut.com/hc/en-us/articles/360009426434-Machine-cannot-read-the-cut-sensor-marks).

### Maximum size
- **What**: the sensor marks take part of the page, so the printable and cuttable area is
  smaller than the sheet and differs by machine. Examples for A4:
  - Joy 2: about 10.62 × 3.07 in.
  - Maker series: about 10.62 × 7.2 in.
  - Joy Xtra: A4 or Letter pages.
  - Venture: up to 24 × 28 in.
- **Page size**: the default page size is set in Settings › Print Then Cut Settings, per
  machine.
- **Sources**: [how large](https://help.cricut.com/hc/en-us/articles/360009429814-How-large-can-I-Print-Then-Cut), [Design Space Settings](https://help.cricut.com/hc/en-us/articles/360023589934-Design-Space-Settings), [Joy Xtra guide](https://help.cricut.com/hc/en-us/articles/26308155935895-Cricut-Joy-Xtra-Quick-Start-Guide).

### Calibration
- **What**: a printed test sheet aligns the sensor with the printer. Required again after
  some updates; for example, everyone had to recalibrate after the June 2022 change.
- **Where**: desktop: menu › Calibration › Print Then Cut. iOS/Android: menu › Settings ›
  Print Then Cut Settings › Calibrate.
- **Availability**: not offline on iOS.
- **Sources**: [calibration](https://help.cricut.com/hc/en-us/articles/360009424974-Calibrating-your-machine-for-Print-Then-Cut), [Design Space FAQ](https://help.cricut.com/hc/en-us/articles/360009503353-Design-Space-FAQ).

### Compatible materials
- **What**: printable vinyl, sticker paper, printable iron-on and others suit Print Then Cut.
- **Sources**: [compatible materials](https://help.cricut.com/hc/en-us/articles/360009558493-Print-Then-Cut-Compatible-Materials).

### Change to plain Cut
- **What**: if the marks cannot be read and you only need the cut, switch the layer from
  Print Then Cut to Cut.
- **Sources**: [upload images](https://help.cricut.com/hc/en-us/articles/360009556313-How-to-upload-images-into-Design-Space).

### Machine-specific guides
- **What**: separate Print Then Cut walkthroughs exist for Explore 5 and Joy 2.
- **Sources**: [Explore 5 Print Then Cut](https://help.cricut.com/hc/en-us/articles/38613592650903-How-to-Print-Then-Cut-with-Cricut-Explore-5), [Joy 2 Print Then Cut](https://help.cricut.com/hc/en-us/articles/38613888983831-How-to-Print-Then-Cut-with-Cricut-Joy-2).

### StickerPix printers
- **What**: Cricut StickerPix Print and StickerPix Print + Cut (2026) are Cricut's own
  printers for photo prints, labels and sticker sheets. They come with templates and
  AI-assisted photo and sticker transformations in Design Space.
- **Sources**: [StickerPix Print + Cut features](https://help.cricut.com/hc/en-us/articles/43562317923095-Understanding-Design-Space-features-for-Cricut-StickerPix-Print-Cut), [StickerPix Print features](https://help.cricut.com/hc/en-us/articles/43596127578775-Understanding-Design-Space-features-for-Cricut-StickerPix-Print), [stickers with StickerPix](https://help.cricut.com/hc/en-us/articles/43648571996055-How-to-make-stickers-with-Cricut-StickerPix-Print-Cut).
