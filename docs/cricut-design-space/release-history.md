# Release history

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02. These are headline features only; the release notes
are mostly bug fixes. Sources: [release notes](https://help.cricut.com/hc/en-us/articles/27054006457111-Design-Space-Release-Notes),
[older release notes](https://help.cricut.com/hc/en-us/articles/29247748906519-Older-Design-Space-Release-Notes),
[blog: what's new](https://cricut.com/blog/gb/design-space-updates-whats-new/), and the
blog posts named below.

| Version / date | Feature |
| --- | --- |
| v10.10 (2026-11-02) | Change a project's base type from the Canvas preview; the help chatbot docks on the right, or floats on the Canvas; faster with raster images and Templates; many StickerPix fixes |
| v10.8 (2026-10-19) | New Upload panel for images, SVGs and other files, with fewer steps, clearer formats and errors |
| v10.5 (2026-09-30) | AI Text edit in the AI Styles panel |
| v9.72 (2026-06-08) | Auto Save on by default for new projects; toggle in the Save menu |
| 2026 (February) | Joy 2 and Explore 5 launch with guided flows, live preview on real objects, and Create AI for subscribers ([blog](https://cricut.com/blog/meet-cricut-joy-2-and-cricut-explore-5/)) |
| 2026 | AI Project Designer, a conversational project builder ([blog](https://cricut.com/blog/cricut-launches-ai-project-designer/)) |
| 2026 | Maker 5 and StickerPix printers supported |
| earlier | Create AI ([blog](https://cricut.com/blog/introducing-create-ai/)) and an AI Generated filter in Images |
| v8.15 / 5.47.0 (December 2023) | Create Sticker (die cut or kiss cut, border, auto-flatten) |
| 5.42.0–5.44.0 (fall 2023) | Warp extended to multi-layer text, images and shapes |
| v7.31 | Warp introduced (30 styles) |
| older | Combine (Unite, Subtract, Intersect, Exclude) as a non-destructive alternative to Weld/Slice |
| older | Equal-distance Smart Guides |
| older | Background Remover in the upload flow; the simple/moderate/complex image choice removed in favour of Reduce Colors and Color Tolerance |
| June 2022 | Print Then Cut change that required everyone to recalibrate |

Desktop and mobile version numbers differ, and the help centre mixes them. Treat
version-to-date pairs as approximate.
