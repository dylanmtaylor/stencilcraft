# Shapes

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02.

### Shapes panel
- **What**: click a shape to place it on the Canvas.
- **Options**: a set of free basic shapes, including square, circle, triangle, heart, star,
  the regular polygons and a score line. More shapes come with Cricut Access or by purchase.
- **Sources**: [Shapes panel](https://help.cricut.com/hc/en-us/articles/4412926883223-Shapes-Panel-in-Design-Space).

### More Shapes
- **What**: a link that opens Images with the Shapes category and the single-layer filter
  already set.
- **Sources**: [Shapes panel](https://help.cricut.com/hc/en-us/articles/4412926883223-Shapes-Panel-in-Design-Space).

### Score line
- **What**: a straight line shape intended for the Score operation (fold lines). Attach it
  to a cut layer so it scores in place.
- **Sources**: [Shapes panel](https://help.cricut.com/hc/en-us/articles/4412926883223-Shapes-Panel-in-Design-Space), [Attach](https://help.cricut.com/hc/en-us/articles/360009380514-How-to-use-Attach-in-Design-Space).

### Unlocked proportions
- **What**: a shape keeps its proportions by default. Unlock the size lock on the Edit bar
  to stretch it (a square becomes a rectangle, a circle an oval).
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).
