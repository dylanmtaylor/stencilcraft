# Keyboard shortcuts

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02. The full list is inside the app (Help › Keyboard
shortcuts, and in Settings). It needs sign-in, so only the shortcuts named in public help
articles are listed here. On Mac, Ctrl is Cmd.

| Action | Shortcut | Source |
| --- | --- | --- |
| Group / Ungroup | Ctrl+G | [Combine, Slice and Weld](https://help.cricut.com/hc/en-us/articles/9503908902551-Using-Combine-Slice-and-Weld-to-create-new-shapes-in-Design-Space) |
| Duplicate | Ctrl+D | same |
| Slice | Shift+Alt+Q | same |
| Attach / Detach | Alt+A | same |
| Flatten / Unflatten | Alt+F | same |
| Add to selection | Shift-click or Ctrl-click (Shift or Cmd on Mac) | same |
| Cut / copy / paste letters in a text box | the usual clipboard keys, or right-click | [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text) |
| Toggle the grid | listed in the in-app shortcut list (key not given publicly) | [Design Space FAQ](https://help.cricut.com/hc/en-us/articles/360009503353-Design-Space-FAQ) |

Still to find from public sources: the shortcuts for undo/redo, zoom, arrange, align and
weld.
