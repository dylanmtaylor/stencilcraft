# Text

Part of the [Cricut Design Space feature library](README.md). Written in our own words from
public sources, retrieved 2026-11-02.

### Add text
- **What**: places a text box on the Canvas. The Edit bar then shows the text controls.
- **Where**: Design panel › Text.
- **Sources**: [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text).

### Font picker
- **What**: choose a font.
- **Options**: tabs (system fonts, Cricut fonts), a search field, keyword buttons, and
  filters. One filter shows only kerned fonts, whose letter pairs are spaced for a natural
  look.
- **Availability**: system fonts are free and work offline. Many Cricut fonts need Cricut
  Access or a purchase, and must be downloaded to use offline.
- **Sources**: [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text), [offline feature](https://help.cricut.com/hc/en-us/articles/360033894014-Design-Space-Offline-Feature).

### Font style
- **What**: regular, bold, italic and, for fonts that have one, a writing (single-line)
  style for pens.
- **Sources**: [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text).

### Font size
- **What**: point size of the text.
- **Sources**: [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text).

### Letter space
- **What**: more or less space between letters in the box. A 2026 fix stopped the value
  resetting to 0.
- **Sources**: [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text), [release notes](https://help.cricut.com/hc/en-us/articles/27054006457111-Design-Space-Release-Notes).

### Line space
- **What**: more or less space between lines in the box.
- **Sources**: [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text).

### Text alignment
- **What**: left, centre or right alignment of the lines in a box.
- **Sources**: [Canvas screen guide](https://help.cricut.com/hc/en-us/articles/26751604105879-Canvas-screen-Design-Space-Guide).

### Curve
- **What**: bends single-line text into a circular arc of a chosen diameter.
- **Rules**: works only on a box with one line, so split lines first. It cannot be used on
  text that was ungrouped to letters and regrouped, so curve before any manual letter
  spacing.
- **Where**: the Effects or Adjustments menu, depending on version.
- **Sources**: [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text).

### Ungroup to Lines / Ungroup to Letters
- **What**: one Ungroup on text separates the lines but keeps the letters together.
  Ungroup again on a single line splits it into separate letters.
- **Rule**: after splitting, letters that touch must be welded or united before cutting,
  or every outline is cut.
- **Sources**: [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text).

### Text editing clipboard
- **What**: cut, copy and paste selected letters inside a text box, from the keyboard or
  the right-click menu.
- **Sources**: [Working with Text](https://help.cricut.com/hc/en-us/articles/5280755261719-Design-Space-Working-with-Text).

### Warp on text
- **What**: see [edit bar › Warp](edit-bar.md#warp). Warped text cannot be ungrouped to
  letters, welded or sliced.
- **Sources**: [Warp](https://help.cricut.com/hc/en-us/articles/11736800185623-How-to-use-Warp-in-Design-Space).
