StencilCraft portable mode

While this file sits next to stencilcraft.exe, StencilCraft keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the StencilCraftData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move StencilCraft with its
settings. The first time StencilCraftData is created, any settings already in
%APPDATA%\StencilCraft are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders StencilCraft loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\StencilCraft) instead.
If StencilCraftData can't be written (for example on a read-only drive), StencilCraft logs a
warning and uses %APPDATA%\StencilCraft instead.
